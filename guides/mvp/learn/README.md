# IDRM — 101 Guide Library

Short, novice-friendly **101 / intermediate / advanced** guides that back the specs and the
[learning paths](../00-start-learning-paths.md). Each guide follows the same **quality bar**: define every term
on first use, build from first principles, show worked examples, explain the *why*, and end with a **mastery
check** (a capability, not a quiz).

**File scheme:** `<name>-101.md` (kebab-case). **Bold = MVP-relevant now**; the rest are FFP fundamentals.
