## How these guides are written

Each guide has the same four parts, so you can read start-to-finish or jump to what you need:

1. **Get started** — a short, guided walkthrough for your first time.
2. **How to…** — step-by-step recipes for everyday tasks.
3. **Reference** — what the screens, statuses, and terms mean.
4. **Understand** — a little background on *why*, when it helps.

**Written for everyone:** plain language, short steps, and designed to meet **WCAG 2.2 AA** accessibility.
The interface is **mobile-first** and **multilingual-ready** (English, Hindi, Tamil planned). Screenshots will
be added as the interface is built.

## The big picture (how your work fits)

IDRM turns a **need** into coordinated **response**, then learns from it (Poster 7):

**Monitor → Assess → Incident → Resources → Communicate → Respond → Recover → Evaluate → Improve**

Wherever you sit in that flow, your guide focuses on *your* part. Any unfamiliar word is in the
[glossary](../90-glossary.md).
