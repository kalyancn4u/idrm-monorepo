How it works

  1. 1

    Request help

    Pin your location, pick what you need (medical, food, shelter…), and submit in seconds.

  2. 2

    Approved & matched

    Authorities review (emergencies are auto-approved) and a nearby verified provider accepts it.

  3. 3

    Help arrives

    Track status live, then confirm completion. Your privacy is protected throughout.
