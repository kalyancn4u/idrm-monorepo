How it works

1 · Request

Start in seconds with phone + OTP. Drop a pin, pick a service type, set urgency.

2 · Match

Authorities approve (emergencies auto-approve); nearby providers accept on the map.

3 · Track

Follow every status change live, then confirm completion and rate the help.
