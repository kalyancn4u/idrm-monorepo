# IDRM — Presentation Decks

Stakeholder-facing slide decks for IDRM (MVP), plus the companion notes and the documentation blueprint they were
built from. These are for **briefings and reviews** — the authoritative detail lives in [`../posters/`](../posters/)
and [`../docs/`](../docs/).

## What's here

| File | What it is |
|---|---|
| **`IDRM-MVP-v3.pptx`** / `IDRM-MVP-v3.pdf` | **The latest deck** (recommended) — MVP overview, native poster-matched design, MVP-only content in the posters' order |
| `IDRM-MVP-v2.pptx` / `.pdf` | Previous revision (kept for history) |
| `IDRM-MVP.pptx` / `.pdf` | The original ~45-slide deck |
| `IDRM_MVP_Comprehensive_Presentation.pptx` | A fuller, comprehensive variant |
| `IDRM_MVP_Stakeholder_SDLCS_Guide.pptx` | Stakeholder-oriented SDLC walkthrough |
| [`IDRM-MVP-presentation-companion.md`](IDRM-MVP-presentation-companion.md) | **Speaker/companion notes** — the narrative to present alongside the slides |
| [`idrm-mvp-documentation-blueprint.md`](idrm-mvp-documentation-blueprint.md) | The 25-document + guides **blueprint** — the plan the whole documentation set was built against |

## Which one to use

- **Presenting to stakeholders?** Use **`IDRM-MVP-v3.pptx`** (or its PDF) with the
  [companion notes](IDRM-MVP-presentation-companion.md).
- **Want the fullest coverage?** `IDRM_MVP_Comprehensive_Presentation.pptx`.
- **Curious how the docs were planned?** [`idrm-mvp-documentation-blueprint.md`](idrm-mvp-documentation-blueprint.md).

> The decks reflect the MVP as of their creation. For the current, authoritative status of the project, see the
> repository front door [`../README.md`](../README.md) and [`../docs/09-roadmap.md`](../docs/09-roadmap.md).
